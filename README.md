# Reshade Shaders
Random ReShade projects of mine which I will slowly accumulate in this repository.

## Shader Descriptions

### LiveResample
A shader that accumulates a certain amount of frames, then blends them together to resample a higher framerate into a smoother, lower framerate for low refresh rates.
